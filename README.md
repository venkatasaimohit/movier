# 🎬 MovieR - React Movie App

MovieR is a modern movie browsing web application built using React and Vite.  
Users can explore popular movies, search for movies, and save favorites using AWS cloud services.

---

## 🚀 Live Demo

🔗 https://movier-pi.vercel.app/

---

## 📌 Features

- 🔥 View Popular Movies
- 🔎 Search Movies
- ❤️ Favorite Movies
- ☁️ AWS Cloud Integration
- ⚡ Fast React + Vite Performance
- 📱 Responsive UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Vite
- CSS

### APIs
- TMDB API

### Cloud Services
- AWS Lambda
- AWS API Gateway
- AWS DynamoDB

### Hosting
- Vercel
